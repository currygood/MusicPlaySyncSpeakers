## 💾 音频主节点-分区表（双备份 OTA，主节点 8MB Flash）

> **注**：分区表按主节点 8MB Flash 设计；从节点为 ESP32-S3-N16R8（16MB Flash），固件不含蓝牙 / LVGL / SD 卡组件，可采用相同双备份 OTA 布局并放大 ota_0/ota_1 分区（如各 6MB）。

由于 UI 资源全部迁移至 SD 卡，Flash 分区专为 OTA 升级设计，无需 SPIFFS 分区。8MB Flash 总容量为 **8,388,608 字节**。

```csv
# Name,      Type, SubType,   Offset,    Size,      Flags
nvs,         data, nvs,       0x9000,    24K,
phy_init,    data, phy,       0xf000,    4K,
otadata,     data, ota,       0x10000,   8K,
ota_0,       app,  ota_0,     0x20000,   0x280000,  # 2.5MB
ota_1,       app,  ota_1,     0x2A0000,  0x280000,  # 2.5MB
storage,     data, spiffs,    0x520000,  0x2C0000,  # 2.75MB（预留）
```

### 空间占用分析

| 分区                  | 起始地址     | 结束地址     | 大小       | 说明                                    |
| :-------------------- | :----------- | :----------- | :--------- | :-------------------------------------- |
| Bootloader + 表头     | 0x0000       | 0x9000       | 36KB       | 系统保留                                |
| NVS                   | 0x9000       | 0xF000       | 24KB       | 存储蓝牙配对信息、WiFi 配置、节点角色等 |
| PHY Init              | 0xF000       | 0x10000      | 4KB        | 射频校准数据                            |
| **otadata**           | **0x10000**  | **0x12000**  | **8KB**    | **OTA 启动选择标志**                    |
| **ota_0（固件区 A）** | **0x20000**  | **0x2A0000** | **2.5MB**  | 当前运行固件 / 升级目标区 1             |
| **ota_1（固件区 B）** | **0x2A0000** | **0x520000** | **2.5MB**  | 当前运行固件 / 升级目标区 2             |
| **storage（预留）**   | **0x520000** | **0x7E0000** | **2.75MB** | 预留用于设备证书、调试日志或未来扩展    |
| 未分配                | 0x7E0000     | 0x800000     | ~128KB     | Flash 末端保留                          |

### 📊 空间使用总览

```reStructuredText
8MB Flash 布局 (0x000000 - 0x800000)
├── 0x000000 - 0x009000  : Bootloader + 分区表 (36KB)
├── 0x009000 - 0x00F000  : NVS (24KB)
├── 0x00F000 - 0x010000  : PHY Init (4KB)
├── 0x010000 - 0x012000  : otadata (8KB)
├── 0x020000 - 0x2A0000  : ota_0 (2.5MB) ← 当前运行/升级目标
├── 0x2A0000 - 0x520000  : ota_1 (2.5MB) ← 当前运行/升级目标
├── 0x520000 - 0x7E0000  : storage (2.75MB) ← 预留扩展
└── 0x7E0000 - 0x800000  : 未分配 (128KB)
```

## 🔄 OTA 升级流程

### 音频节点（ESP32）

采用双备份 OTA 分区（ota_0 / ota_1），支持远程升级与异常回滚。

### 灯控节点（ESP8266）

ESP8266 采用单分区 OTA（4MB Flash），通过 HTTP 下载新固件并写入备用区域，重启后自动切换。

### ESP-IDF OTA 相关配置（来源：menuconfig 章节）

```ini
# OTA
CONFIG_ESP_OTA=y
CONFIG_BOOTLOADER_APP_ROLLBACK_ENABLE=y
```
