## 🔌 完整引脚接线表(完全针对项目，不需要使用完全上面提到的引脚)

> **⚠️ 重要说明**：ESP32-WROVER-IB 内部 SPI Flash 占用 **GPIO6~11**，这些引脚**不可用于外部电路**。以下分配已避开所有受限引脚。

### 推荐引脚分配（主节点专用 PCB）

> 下表为**主节点（ESP32-WROVER-E-N16R8 自制 PCB）**的完整引脚分配；从节点开发阶段使用现成 ESP32-S3 开发板（目标硬件与主节点同款），不装屏/不插 SD 卡/不焊麦克风，仅需连接功放 + 喇叭 + 状态灯，见下方“从节点接线表”。

| 模块                       | 信号        | GPIO | 备注                                                         |
| :------------------------- | :---------- | :--- | :----------------------------------------------------------- |
| **LCD (SPI)**              | LCD_CS      | 4    | 片选                                                         |
|                            | LCD_RST     | 25   | 复位，不能少                                                 |
|                            | LCD_RS (DC) | 22   | 命令/数据选择                                                |
|                            | MOSI        | 18   | SPI 数据输入（与 SD 卡共用总线）                             |
|                            | SCK         | 19   | SPI 时钟（与 SD 卡共用总线）                                 |
|                            | MISO        | 21   | SPI 数据输出（与 SD 卡共用总线）                             |
|                            | LED         | 23   | 背光控制（只做开/关，不做 PWM 调光；Strapping 脚需谨慎）     |
| **SD 卡 (SPI)**            | SD_CS       | 15   | 片选（与 LCD 分时复用 SPI 总线）                             |
| **触摸屏 (I²C)**           | CTP_SDA     | 32   | I²C 数据                                                     |
|                            | CTP_SCL     | 33   | I²C 时钟                                                     |
|                            | CTP_INT     | 2    | 飞线接入，中断触发 + 兜底轮询（模块上拉，静止为高）          |
|                            | CTP_RST     | 25   | 电容触摸屏复位控制信号，低电平复位 。不能少！！！，必须要软件复位，它不会自动复位 |
| **功放 (I2S)**             | BCLK        | 26   | I2S 位时钟                                                   |
|                            | LRCLK       | 27   | I2S 左右声道时钟                                             |
|                            | SDIN        | 13   | I2S 数据输入                                                 |
|                            | MCLK        | 悬空 | 主时钟（NS4168 内部可倍频，无需外接）                        |
| **麦克风 (I2S)**           | —           | —    | **已下线，不需要焊接/接线**：语音唤醒链路删除，原 GPIO 34 / 2 / 5 已释放（GPIO2 改作触摸 INT） |
| 按键1                      | 一端        | 36   | 另一端是GND，低电平有效，pcb设计要有上拉电阻，因为这个gpio口只有输入功能，里面没有内部上拉/下拉 |
| **电源**                   | VCC         | -    | 3.3V / 5V（按模块要求）                                      |
|                            | GND         | -    | 公共地                                                       |

1. **共用复位（GPIO 25）的时序兼容**： LCD 和触摸屏共用 GPIO 25 复位时，需确保两者的复位逻辑一致（均为低电平复位）。软件拉低 GPIO 25 后，**必须保持足够的低电平时间（建议 >20ms）**，以同时满足 LCD 和触摸屏的复位脉冲宽度要求，然后再拉高。   **直接一起在LCD屏复位的时候复位即可，后面初始化触摸屏就不需要复位了。**

2. Strapping 引脚的外部电路禁忌

   ： 对于使用的 Strapping 引脚（GPIO 15, 2），外部电路绝对不能添加与之冲突的上下拉电阻。

   - **GPIO 15 (SD_CS)**：外部**严禁**接地或接下拉电阻，必须依靠内部上拉或外部上拉保持高电平。
   - **GPIO 2 (CTP_INT 飞线)**：模块上拉使静止为高，触摸中断按下降沿触发；若某天无法进入下载模式，先拔掉这根飞线再试（见 `LCD_Touch.h`）。

3. **再次警告 GPIO 12**： 无论引脚多么紧张，**绝对不要**将任何外设分配到 GPIO 12。上电时若被拉高，会将模组内部 Flash/PSRAM 的供电电压强制切换为 1.8V，导致模组直接“变砖”且无法恢复。

### 从节点接线表（ESP32-S3 开发板，I2S 功放 + 喇叭 + 状态灯）

| 模块                  | 信号 | 开发板引脚（示例） | 备注                                    |
| --------------------- | ---- | ------------------ | --------------------------------------- |
| **功放 NS4168 (I2S)** | BCLK | GPIO8            | I2S 位时钟（以实际开发板可用引脚为准）   |
|                       | LRCLK| GPIO9            | I2S 左右声道时钟                         |
|                       | SDIN | GPIO10           | I2S 数据输入                             |
| **状态灯**            | LED  | GPIO15           | 状态指示（高电平点亮）                   |
| **电源**              | VCC  | 3.3V / 5V          | 按功放模块要求                           |
|                       | GND  | GND                | 公共地                                   |

> **提示**：示例引脚为一般空闲引脚，实际接线以手头开发板为准。

###  ESP8266 灯控节点引脚接线表

⚠️ **重要说明**：ESP8266 的 GPIO6~11 被内部 Flash 占用。灯控节点只驱动**一路继电器**，只有开/关两态，不做 PWM 调光、没有亮度概念。

| 模块   | 信号   | GPIO  | 备注                                                         |
| ------ | ------ | ----- | ------------------------------------------------------------ |
| 卧室灯 | 继电器 | GPIO0 | 高电平吸合（开灯）/低电平释放（关灯），上电默认关；GPIO0 兼作启动模式选择，复位前须先拉高 |
| 电源   | VCC    | 3.3V  |                                                              |
|        | GND    | GND   | 公共地                                                       |
