## 🔌 完整引脚接线表(完全针对项目，不需要使用完全上面提到的引脚)

> **⚠️ 重要说明**：ESP32-WROVER-IB 内部 SPI Flash 占用 **GPIO6~11**，这些引脚**不可用于外部电路**。以下分配已避开所有受限引脚。

### 推荐引脚分配（主节点专用 PCB）

> 下表为**主节点（ESP32-WROVER-E-N8R8 自制 PCB）**的完整引脚分配；从节点使用现成 ESP32-S3 开发板，无需以下外设，仅需连接功放与喇叭，见下方“从节点接线表”。

| 模块                       | 信号        | GPIO | 备注                                                         |
| :------------------------- | :---------- | :--- | :----------------------------------------------------------- |
| **LCD (SPI)**              | LCD_CS      | 4    | 片选                                                         |
|                            | LCD_RST     | 25   | 复位，不能少                                                 |
|                            | LCD_RS (DC) | 22   | 命令/数据选择                                                |
|                            | MOSI        | 18   | SPI 数据输入（与 SD 卡共用总线）                             |
|                            | SCK         | 19   | SPI 时钟（与 SD 卡共用总线）                                 |

|                            | LRCLK       | 27   | I2S 左右声道时钟                                             |
|                            | SDIN        | 13   | I2S 数据输入                                                 |
|                            | MCLK        | 悬空 | 主时钟（NS4168 内部可倍频，无需外接）                        |
| **麦克风 (I2S，仅主节点)** | SD          | 34   | 数据输出到esp32 (PDM_DATA)                                   |
|                            | CLK         | 2    | 时钟输入到INMP441 (PDM_CLK)                                  |
|                            | WS          | 5    | I2S 左右声道时钟 (LRCK)                                      |
|                            | L/R         | GND  | 左/右声道选择（接地 = 左声道）它是用来解决"两个 INMP441 共用一条 I2S 总线"的场景：一个接 GND 输出左声道，一个接 VDD 输出右声道，实现立体声采集。 本项目只有一个INMP441，所以就直接接地 |

|                            | GND         | -    | 公共地                                                       |

1. **共用复位（GPIO 25）的时序兼容**： LCD 和触摸屏共用 GPIO 25 复位时，需确保两者的复位逻辑一致（均为低电平复位）。软件拉低 GPIO 25 后，**必须保持足够的低电平时间（建议 >20ms）**，以同时满足 LCD 和触摸屏的复位脉冲宽度要求，然后再拉高。   **直接一起在LCD屏复位的时候复位即可，后面初始化触摸屏就不需要复位了。**

2. Strapping 引脚的外部电路禁忌

   ： 对于使用的 Strapping 引脚（GPIO 15, 2, 5），外部电路绝对不能添加与之冲突的上下拉电阻。

   - **GPIO 15 (SD_CS)**：外部**严禁**接地或接下拉电阻，必须依靠内部上拉或外部上拉保持高电平。
   - **GPIO 2 (MIC_CLK)**：外部**严禁**接上拉电阻，必须依靠内部下拉或外部下拉保持低电平。
   - **GPIO 5 (MIC_WS)**：外部**严禁**接地或接下拉电阻。

3. **再次警告 GPIO 12**： 无论引脚多么紧张，**绝对不要**将任何外设分配到 GPIO 12。上电时若被拉高，会将模组内部 Flash/PSRAM 的供电电压强制切换为 1.8V，导致模组直接“变砖”且无法恢复。

###  ESP8266 灯控节点引脚接线表

⚠️ **重要说明**：ESP8266 的 GPIO16 不支持 PWM，GPIO6~11 被内部 Flash 占用。以下分配使用软件 PWM，支持最多 6 路输出，刚好满足两盏 RGB 灯的需求。

| 模块   | 信号    | GPIO  | 备注     |
| ------ | ------- | ----- | -------- |
| 卧室灯 | PWM输入 | GPIO5 | PWM 输入 |
| 客厅灯 | B       | GPIO4 | PWM 输入 |
| 电源   | VCC     | 3.3V  |          |
|        | GND     | GND   | 公共地   |
