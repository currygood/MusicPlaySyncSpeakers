## UDP组播的json完整格式：

```json
{
  "cmd": "on",
  "light": "bedroom",
}
```

1. cmd为开关命令，继电器只能做到开关灯，所以cmd命令只有：`on` `off`   两个命令
2. light为哪里的灯，目前测试只有一个  `bedroom`
3. 而且调不了亮度，所以没有brightness
