## 🧩 硬件要求

### 核心组件

| 组件         | 型号                                 | 说明                                                         |
| :----------- | :----------------------------------- | :----------------------------------------------------------- |
| **主控（主节点）** | ESP32-WROVER-E-N16R8             | ESP32-D0WD 芯片，双核 240MHz，16MB Flash + 8MB PSRAM，支持蓝牙 v4.2 双模（BR/EDR + BLE），集成 802.11 b/g/n Wi-Fi |
| **主控（从节点）** | 目标同为 ESP32-WROVER-E-N16R8；开发阶段用 ESP32-S3 开发板（如 ESP32-S3-N16R8）替代 | 目标硬件与主节点同款（16MB Flash + 8MB PSRAM）；开发阶段 `Play_Slave/sdkconfig` 为 `esp32s3`：ESP32-S3 芯片，双核 240MHz，16MB Flash + 8MB PSRAM，支持 BLE 与 Wi-Fi，**无经典蓝牙（BR/EDR），不支持 A2DP 蓝牙音乐接收** |
| **显示屏**   | 2.8 寸 IPS SPI 模块（ILI9341）       | 320×240 分辨率，4 线 SPI，自带 Micro SD 卡槽 。只有音频主节点有 |
| **触摸屏**   | 电容触摸（FT6336G）                  | I²C 接口                                                     |
| **音频功放** | NS4168                               | I2S 数字输入，单声道 D 类，2.5W 输出，内置 DAC               |
| **麦克风**   | ~~INMP441~~                          | **已下线，不需要焊**：语音唤醒链路删除，INMP441 不再选型（代码已移入 `Play_Master/legacy_disabled`） |
| **存储卡**   | Micro SD 卡（SPI 模式）              | FAT32 格式，存放音频文件（/music）；UI 图片放 Flash storage 分区          |
| **扬声器**   | 4Ω 3W 喇叭                           | 单声道输出                                                   |
| **电源**     | 设计的板子有电源，用电池供电，可充电 | 为整板供电                                                   |

> **⚠️ 重要提示**：
>
> - 目标硬件主/从同款（ESP32-WROVER-E-N16R8），固件分开编译；从节点开发阶段用 ESP32-S3 开发板替代，通过 NVS 保存各节点运行参数。
> - 从节点**不装屏、不插 SD 卡、不焊麦克风**，仅使用 ESP32-S3 开发板 + I2S 功放 + 喇叭 + 状态灯（GPIO15）（无触摸屏 / SD 卡 / 经典蓝牙），进一步降低 BOM 成本。
> - 从节点**不实现“无主节点时切换蓝牙模式”**：ESP32-S3 仅支持 BLE（无经典蓝牙 A2DP），无法作为蓝牙音源接收端。
> - UI 图片资源（3 张 PNG）与中文字体 TTF 随固件烧录进 Flash storage 分区，图标字形编译进固件；音乐文件从 SD 卡加载，Flash 双备份 OTA 不变。
> - 两个节点需连接**同一 WiFi 路由器**（同一局域网），以支持 UDP 组播通信。

### 显示屏模块详解（LCD2.8 寸 IPS SPI 模块）

该模块基于 **ILI9341V** 驱动芯片，采用 4 线制 SPI 串行总线，板载电平转换电路，兼容 5V 和 3.3V MCU。

**关键参数：**

| 参数        | 规格                              |
| :---------- | :-------------------------------- |
| 屏幕尺寸    | 2.8 inch                          |
| 屏幕类型    | IPS（全视角）                     |
| 分辨率      | 240 × RGB × 320 (pixels)          |
| 驱动 IC     | ILI9341V                          |
| 显示接口    | 4-Line SPI                        |
| 最大颜色数  | 262K                              |
| 背光亮度    | 280 cd/m²                         |
| 触摸屏类型  | 电容触摸                          |
| 触摸驱动 IC | FT6336G                           |
| 触摸接口    | I²C                               |
| **SD 卡槽** | 自带 Micro SD 卡槽，支持 SPI 模式 |

### NS4168 音频功放详解

NS4168 是一款支持 I2S 数字音频信号输入、输出具有防失真功能的单声道 D 类音频功率放大器。

**关键特性：**

- **内置 DAC**：可直接接收 ESP32 的 I2S 数字音频信号并进行放大，无需外接其他解码芯片
- **工作电压**：3.0V ~ 5.5V
- **输出功率**：最高 2.5W（VDD=5V, RL=4Ω）
- **信噪比**：85dB
- **总谐波失真+噪声**：0.2%
- **采样率支持**：8kHz ~ 96kHz
- **功放类型**：D 类，无滤波器架构

**引脚定义：**

| 引脚  | 名称  | 功能                                  |
| :---- | :---- | :------------------------------------ |
| Pin 1 | CTRL  | 控制/静音引脚（高电平使能，拉低静音） |
| Pin 2 | LRCLK | I2S 帧时钟（左右声道时钟）            |
| Pin 3 | BCLK  | I2S 位时钟                            |
| Pin 4 | SDATA | I2S 串行音频数据输入                  |
| Pin 5 | VON   | BTL 输出负端                          |
| Pin 6 | VDD   | 主供电引脚                            |
| Pin 7 | GND   | 信号地                                |
| Pin 8 | VOP   | BTL 输出正端                          |
| Pin 9 | EP    | 底部散热焊盘，连接大面积地平面        |

### INMP441 麦克风（已下线）

**已下线，不需要焊接**：语音唤醒链路整体删除（`CallPhone` / `microphone` 移入 `Play_Master/legacy_disabled`，`sdkconfig` 删 `esp-sr`，HFP 代码保留但无调用者），麦克风不再选型，原有引脚（GPIO34 / 2 / 5）已释放——其中 GPIO2 现用于触摸 INT 飞线。原选型与引脚说明不再保留。
