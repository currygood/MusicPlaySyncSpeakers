## 💾 音频主节点-分区表（双备份 OTA，16MB Flash）

> **注**：分区表按主节点实际 `partitions.csv` 列出（ESP32-WROVER-E-N16R8，16MB Flash）。从节点开发阶段为 ESP32-S3-N16R8（同为 16MB Flash），分区表也有 ota_0/ota_1 槽位，但 `ota_manager` 目前是空壳，OTA 尚未接线。

UI 图片资源（3 张 PNG）存放在 SPIFFS `storage` 分区（随固件烧录，见 `storage/ui_img/`）；`model` 为后续模型资源预留。

```csv
# Name,      Type, SubType,   Offset,    Size,      Flags
nvs,         data, nvs,       0x9000,    24K,
phy_init,    data, phy,       0xf000,    4K,
otadata,     data, ota,       0x10000,   8K,
ota_0,       app,  ota_0,     0x20000,   0x400000,  # 4MB
ota_1,       app,  ota_1,     0x420000,  0x400000,  # 4MB
model,       data, spiffs,    0x820000,  0x80000,   # 512KB
storage,     data, spiffs,    0x8A0000,  0x740000,  # 7.25MB（UI 图片，随固件烧录）
coredump,    data, coredump,  0xFE0000,  0x20000,   # 128KB
```

### 空间占用分析

| 分区                  | 起始地址     | 结束地址     | 大小       | 说明                                    |
| :-------------------- | :----------- | :----------- | :--------- | :-------------------------------------- |
| Bootloader + 表头     | 0x0000       | 0x9000       | 36KB       | 系统保留                                |
| NVS                   | 0x9000       | 0xF000       | 24KB       | 存储蓝牙配对信息、WiFi 凭据、节点角色等 |
| PHY Init              | 0xF000       | 0x10000      | 4KB        | 射频校准数据                            |
| **otadata**           | **0x10000**  | **0x12000**  | **8KB**    | **OTA 启动选择标志**                    |
| *(空余)*              | 0x12000      | 0x20000      | 56KB       | 未分配                                  |
| **ota_0（固件区 A）** | **0x20000**  | **0x420000** | **4MB**    | 当前运行固件 / 升级目标区 1             |
| **ota_1（固件区 B）** | **0x420000** | **0x820000** | **4MB**    | 当前运行固件 / 升级目标区 2             |
| **model**             | **0x820000** | **0x8A0000** | **512KB**  | SPIFFS；模型资源预留                    |
| **storage（UI 图片）** | **0x8A0000** | **0xFE0000** | **7.25MB** | SPIFFS；存放 UI 图片（ui_img/ 3 张 PNG），随固件烧录 |
| **coredump**          | **0xFE0000** | **0x1000000** | **128KB** | 崩溃现场转储                            |

### 📊 空间使用总览

```reStructuredText
16MB Flash 布局 (0x000000 - 0x1000000)
├── 0x000000 - 0x009000  : Bootloader + 分区表 (36KB)
├── 0x009000 - 0x00F000  : NVS (24KB)
├── 0x00F000 - 0x010000  : PHY Init (4KB)
├── 0x010000 - 0x012000  : otadata (8KB)
├── 0x020000 - 0x420000  : ota_0 (4MB) ← 当前运行/升级目标
├── 0x420000 - 0x820000  : ota_1 (4MB) ← 当前运行/升级目标
├── 0x820000 - 0x8A0000  : model (512KB) ← 模型资源预留
├── 0x8A0000 - 0xFE0000  : storage (7.25MB) ← UI 图片（SPIFFS，随固件烧录）
└── 0xFE0000 - 0x1000000 : coredump (128KB)
```

> 与 `Play_Master/partitions.csv` 逐行一致；改分区表时两处一起改，否则 `idf.py` 烧录与文档会两张皮。
