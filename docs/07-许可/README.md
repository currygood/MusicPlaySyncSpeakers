# 07-许可：开源组件授权与合规

本目录保存项目所用第三方组件的**授权依据与本地修改记录**，供发布、审计与二次开发时查阅。

仓库层面的总声明在根目录 [`THIRD_PARTY_NOTICES.md`](../../THIRD_PARTY_NOTICES.md)；本目录是它的"证据层"——每个组件一份文档，记录版本、来源、许可原文位置、本地改动与实测数据。

## 与其它文档的关系

| 文档 | 定位 |
| :--- | :--- |
| 根目录 `LICENSE` | 本项目自身的许可证（Apache-2.0） |
| 根目录 `THIRD_PARTY_NOTICES.md` | 面向分发者的汇总声明（谁、什么版本、什么许可、要做什么） |
| 本目录 `所用开源/*.md` | 单个组件的深挖：来源、SHA256、补丁、实测、升级步骤 |
| `docs/03-开发/第三方依赖与许可证.md` | 依赖清单的开发视角入口 |

## 新增组件的写法

新增一个第三方库时，在本目录 `所用开源/` 下建 `<组件>-授权说明.md`，固定包含：

1. **结论先行**：许可证名 + 能否商用 / 能否闭源分发 + 本项目需要履行什么；
2. **源信息**：上游地址、版本或（若无版本号）SHA256、本地路径；
3. **本地修改**：改了哪几行、为什么改、上游原逻辑是否保留；
4. **在本项目中的用法**：关键参数与调用位置；
5. **义务与维护**：许可要求的动作、升级后要重做什么。

写完后同步更新根目录 `THIRD_PARTY_NOTICES.md` 的对应表格。
