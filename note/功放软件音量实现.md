# 功放软件音量实现笔记（NS4168 无硬件增益）

> 日期：2026-09-30 ｜ 项目：Play_Master（amplifier）

## 1. 现象

- `AMPLIFIER: Volume set to xxx%` 日志正常打印；
- 但功放实际音量**完全不变**，调 100% / 10% 听不出区别。

## 2. 根因

`Amplifier_Set_Volume()` 早期实现只做了“保存变量 + 打印日志”，**没有对 PCM 做任何衰减**；NS4168 是固定增益 D 类功放，没有硬件音量寄存器，音量只能靠软件缩放 PCM。

## 3. 实现方案（已落地）

在 amplifier 模块内实现软件音量：

- 音量曲线：`gain = (vol/100)²`（平方曲线，更接近人耳响度感知）；
- 定点实现：`gain = ((uint32_t)vol * vol * 32768) / 10000`，缩放时 `>> 15`；
- 100% 直通（零开销），0% 直接静音（memset）；
- 工作缓冲**优先 PSRAM**（`MALLOC_CAP_SPIRAM`），失败回退 internal RAM；块大小按音频块上限（如 2048 帧 × 2ch × 2B = 8KB）。

核心逻辑示意：

```c
static int16_t *s_amp_scaled; /* PSRAM 优先 */

esp_err_t Amplifier_Play_Buffer(const uint8_t *buffer, size_t size, ...)
{
    size_t samples = size / (sizeof(int16_t) * 2); /* L/R */
    const int16_t *out = (const int16_t *)buffer;
    if (vol < 100) {
        uint32_t gain = ((uint32_t)vol * vol * 32768u) / 10000u;
        for (i = 0; i < samples * 2; i++)
            s_amp_scaled[i] = (int16_t)(((int32_t)in[i] * gain) >> 15);
        out = s_amp_scaled;
    }
    audio_writer_write(writer, out, samples, ...);
}
```

## 4. 音量来源统一

- 蓝牙音量变化事件 `BT_AUDIO_EVT_VOLUME_CHANGED` → 回调 `Amplifier_Set_Volume()`；
- UI 音量 → 同样调 `Amplifier_Set_Volume()`；
- 这样不管手机调、UI 调、测试调，都落在同一个变量上，下一次 Play 就生效。

## 5. 验证

100 → 70 → 40 → 10 → 60 → 85 各档能听出明显音量台阶；暂停、上一首、下一首正常。

## 6. 注意

- `s_amp_scaled` 需要在 `Amplifier_Init()` 里分配、`Amplifier_Deinit()` 释放；
- 如果缓冲分配失败要打 WARN，并保持直通（保证有声音比没声音好）；
- 定点运算 `int16 × gain(≤32768)` 在 int32 内不会溢出。

## 7. 板级响度校准（主从同一个音量数值，听起来不一样响）

> 2026-10-22 补充：主节点 LCD 调音量时从节点已经能跟随（`ctl_rx`），但同一个
> volume 数值下从节点明显更响。
>
> 2026-10-23 结论：最终确认是**扬声器本身**（灵敏度不同）造成的，换用一致的
> 扬声器后响度已经对齐。板级校准系数因此恢复为 100（不校准），宏保留作以后
> 换喇叭/换腔体时的工具。

排查结论：**数字链路完全一致** —— 两边 `amplifier.c` 是同一个公式
（`(vol/100)²` 定点）、主节点本地播放和从节点收到的也是同一份 PCM、进
`Amplifier_Play_Buffer()` 之前没有任何额外缩放。所以差值不来自代码，而是来自
模拟/声学段：

- 功放供电电压不同（NS4168 输出功率随 VDD 下降；5V 与 3.3V 差约 3.6dB）；
- 喇叭灵敏度不同（同为 4Ω 3W 的廉价喇叭，85~90dB/W 很常见，差几个 dB 正常）；
- 腔体、安装方式不同。

**解决**：`amplifier.h` 增加 `AMPLIFIER_GAIN_TRIM_PERCENT`（线性幅度百分比），
算出平方曲线的 gain 之后叠乘：

```c
uint32_t gain = ((uint32_t)vol * vol * 32768) / 10000u;
#if AMPLIFIER_GAIN_TRIM_PERCENT != 100
gain = (gain * AMPLIFIER_GAIN_TRIM_PERCENT) / 100u;  /* 只衰减，不提升 */
if (gain > 32768u) gain = 32768u;                    /* 0dB 封顶，防削波 */
#endif
```

- 主节点、从节点都保持 100（不校准）；
- 以后换喇叭/换腔体后响度对不上，把偏响的那块板往下调（70、50、35），
  调到听感一致为止；
- 系数为 100 时整段被 `#if` 编译掉，主节点热路径零开销；
- 只改本板出声大小，不改 volume 0~100 的语义（LCD、协议、NVS 都不动）。
