# 麦克风(I2S RX)双槽采样问题笔记

> 日期：2026-09-22 ｜ 项目：Play_Master（ESP32 + INMP441 + NS4168）

## 1. 现象（录音→回放测试）

录音 10 秒后功放回放，出现以下现象：

- 语音变成 **0.5 倍速**（说话被拉慢一倍）
- 说话声音**很小声**，被“嗡嗡嗡”杂音盖住
- 回放时**开头说话内容丢失**

## 2. 根因

I2S RX 配置为：`16kHz / 32bit / 立体声槽位（slot_mask = RIGHT）`。

ESP-IDF 的 `i2s_channel_read()` 原样返回 DMA 数据：**每个 16kHz 帧 = 2 个槽位（L/R）× 32bit**，即每帧产生 **2 个 int32** 样本进入 FIFO。

而 `audio_reader_read_pcm16()` 把**每一个 int32 都当成一个采样**。于是：

> 实际采样率 = 16kHz × 2 = **32kHz**，程序却按 16kHz 处理。

### 症状与根因对应关系

| 现象 | 原因 |
|---|---|
| 0.5 倍速 | 采集到 2 倍样本，按 16kHz 播放 → 时长远超 |
| 说话声小 + 嗡嗡 | 每两个样本里有一个是“未用槽”（静音/残噪），语音能量被稀释一半 |
| 开头丢失 | FIFO(16KB) 溢出 `DROP_OLDEST`，最早的数据被丢 |

### 日志证据

- 录音进度：1 秒内增加约 **32256 个样本**（16k×2=32k，而不是 16k）
- 160000 样本在约 **5 秒**内就采完了（本应 10 秒）
- 反初始化时 `reader[mic_main] unregistered (dropped 1209344 bytes total)`

## 3. 修复方法（软件）

在测试函数 `Mic_Record_Playback_Test()`（`main/app_main.c`）中：

1. **录音时全量采集**两个槽位：`totalSamples = 10 * 16000 * 2`（320000 样本，640KB，用 PSRAM）；
2. **去交错**：录完后统计偶数/奇数下标样本的能量（绝对值累加），保留能量大的那个槽；
3. 相邻两个样本合为一个 → 还原为真正的 **16kHz 单声道** 语音；
4. 后续峰值统计、回放全部基于去交错后的数据。

关键代码示意：

```c
/* 去交错：每 2 个样本 = 1 帧（两个槽位），按能量保留有声音的那个槽 */
int64_t evenEnergy = 0, oddEnergy = 0;
for (size_t i = 0; i + 1 < recorded; i += 2) {
    int64_t a = rec[i], b = rec[i + 1];
    evenEnergy += (a < 0) ? -a : a;
    oddEnergy  += (b < 0) ? -b : b;
}
int keepLane = (evenEnergy >= oddEnergy) ? 0 : 1;
size_t frames = recorded / 2;
for (size_t i = 0; i < frames; i++) {
    rec[i] = rec[i * 2 + keepLane];
}
recorded = frames;
```

> 为什么按能量取槽：INMP441 只在一个槽出力（L/R 脚决定在左槽还是右槽），
> 另一个槽是静态/噪声，用能量比较自动选择即可，不需要关心 L/R 接法。

## 4. 播放侧注意事项

- `Amplifier_Play_Buffer()` 要求 **16bit 立体声交错（L/R 各一份）**：
  `帧数 = size / 4`。
- 单声道→立体声：每个样本写两次（`stereo[2i] = stereo[2i+1] = mono[i]`）。
- 回放增益可用 `MIC_TEST_GAIN` 宏调整（8/12/16/24/32），带 ±32767 限幅。

## 5. INMP441 接线/硬件要点

| 信号 | INMP441 引脚 | GPIO |
|---|---|---|
| SCK（位时钟） | SCK | GPIO2 |
| WS（左右时钟） | WS/LRCK | GPIO5 |
| SD（数据输出） | SD/DOUT | GPIO34 |
| 声道选择 | **L/R** | **直接接 GND 或 3.3V，不要接 MCU！** |

⚠️ 曾经把 GPIO5 错接到 INMP441 的 **L/R** 而不是 WS，导致录音全 0、回放无声。

其他硬件注意：

- GPIO34 是 **输入专用脚，内部没有上下拉**；SD 线不驱动时三态悬空，建议**外部加 100kΩ 下拉到 GND**（日志中 `gpio_pulldown_en` 报错即此原因）；
- 麦克风供电用干净的 3.3V，不要与功放 5V/DCDC 共电，减少 50/100Hz 工频嗡嗡；
- 麦克风与喇叭/功放走线尽量分开。

## 6. 调试技巧

- 录音完成后打印 `record raw peak=xxx active=xxx/xxx`：
  - `peak < 1000` → 麦没采到声，查接线（WS/L/R/SD）；
  - `peak` 正常但有声无名 → 检查槽位/去交错是否正确。
- I2S 总线初始化日志里 BCLK 按公式自检：
  `BCLK = fs × 声道数 × 位宽`
  - 麦克风 RX：`16000 × 2 × 32 = 1024000 Hz`（日志见 `I2S_PHY: BCLK = 1024000 Hz`）
  - 功放 TX：`16000 × 2 × 16 = 512000 Hz`
